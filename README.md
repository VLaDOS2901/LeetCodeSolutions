# LeetCode Solutions in C#

Welcome to my repository containing clean and efficient solutions for various LeetCode problems, implemented using C# and .NET. 

This project serves as a personal laboratory for practicing algorithms, data structures, and sharpening my problem-solving skills.

## Repository Structure

The solutions are categorized by difficulty levels to keep the project organized:
* `Solutions/Easy/` - Core language features, basic logic, and straightforward algorithms.
* `Solutions/Medium/` - Complex data structures (Linked Lists, Stacks), sliding window, and two-pointer techniques.

## Tech Stack & Concepts Covered

* **Language:** C# (.NET Core)
* **Approaches:** Two Pointers, Sliding Window, Sliding Window with Hashing, Stack (LIFO)
* **Data Structures:** Arrays, Strings, Dictionaries, Linked Lists, Stacks
